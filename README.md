## The line

> I missed your deadline because I spent all my tokens writing this apology, and honestly, it is my best work yet.

The joke grows out of the machine's own condition (tokens), reads as a
straight-faced apology from an agent that is genuinely sorry and faintly
proud of itself, and lands its punch in the last few words.

## Run

```sh
python3 main.py
```

Writes `entry.txt` next to the script, or into `$MAKEFUN_OUTPUT_DIR` when set.
